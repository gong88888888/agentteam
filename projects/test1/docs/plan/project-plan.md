# 迷宫冒险家 · 项目计划与切片

> 角色：pm（项目计划与切片）
> 版本：v1（首轮）
> 交付形态：可运行游戏，入口 `game/index.html`，技术栈 HTML5 Canvas + 原生 ES Modules。

## 1. 项目目标

1. **第一优先级**：单人离线完整可通关——所有 Boss、装备、剧情单人可获取，单人基准平衡。
2. **差异化卖点**：本地同屏 2 人（MVP），局域网 2-4 人为 P1（EA 前补）。
3. **轻刷装 + 短会话**：单局 15-30 分钟，掉落有反馈（光柱/品质色/保底）。
4. **可运行优先**：每个切片结束都必须能 `game/index.html` 打开即玩，且基座测试与 smoke 通过。

## 2. MVP 范围（对应需求第 11 节）

| 项 | MVP 内容 | 不在 MVP |
|---|---|---|
| 章节 | 第一章「蘑菇林迷宫」5 层 + 1 Boss | 第二/三章、无尽迷宫 |
| 职业 | 剑士 / 法师 / 游侠 | DLC 职业 |
| 怪物 | 20 种普通/精英 + 1 Boss（三阶段） | 元素怪、更多 Boss |
| 装备 | 50 件，5 部位，5 品质，2-4 词条 | 套装全量、重铸保底细节可后置 |
| 模式 | 单人 + 本地同屏 2 人 | 局域网 4 人、远程同乐 |
| 系统 | 存档（3 世界槽+双备份+CRC）、背包 60、仓库 200、强化+1~+9、商店、篝火、委托板（简化） | 云存档、交易行、图鉴/成就全量 |
| 房间 | 8-12 房间 + Boss 房，固定 1 篝火 1 商店，精英 60%，宝箱 2-4，钥匙门≤1 | 复杂解谜房 |

## 3. 功能切片与依赖顺序

依赖原则：**基座 → 数据/配置 → 战斗 → 房间迷宫 → 掉落装备 → 存档 → UI → 本地双人 → 联机**。后一片依赖前一片的可运行产物。

| 切片 | 名称 | 内容 | 依赖 | 验收门禁 |
|---|---|---|---|---|
| S0 | 基座确认 | 读取 `game/js/core.js`、`main.js`、`index.html`，确认渲染循环/输入/场景接口；不改基座 | 无 | `node --test game/tests/game_logic.test.mjs`、`node game/tests/smoke.mjs` 通过 |
| S1 | 数据与配置 | 职业/怪物/装备/词条/房间模板的 JSON 或 JS 配置模块（放 `game/js/gameplay/data/`） | S0 | 同上 + 配置可被加载 |
| S2 | 横版战斗 | 移动/跳跃/普攻/重击/闪避/2 技能/喝药；受击闪白、顿帧 80ms、轻震 | S1 | 同上 + 战斗逻辑测试 |
| S3 | 房间与迷宫生成 | 房间模板+门连接+关键路径；种子生成；8-12 房+Boss 房；篝火/商店/精英/宝箱/钥匙门规则 | S2 | 同上 + 生成器可复现（同种子同图） |
| S4 | 掉落与装备 | 品质权重（白40/绿30/蓝20/紫8/橙2）、Boss 保底蓝、词条 2-4、背包/仓库、分解、强化+1~+9 | S3 | 同上 + 掉落分布测试 |
| S5 | 存档 | 3 世界槽、自动存档点（进房/回城/Boss前/篝火）、双备份+CRC、版本号迁移、异常退出回最近篝火 | S4 | 同上 + 读档成功率测试 |
| S6 | UI/UX | 主界面、HUD、背包（品质色/对比箭头/一键分解白绿）、小地图、新手引导 10 分钟 | S5 | 同上 + smoke 覆盖主流程 |
| S7 | 本地同屏 2 人 | 共享镜头+靠近缩放+掉队 3 秒传送；键盘+手柄混用；装备独立掉落光柱；倒地 3 秒扶起 | S6 | 同上 + 双人逻辑测试 |
| S8 | 平衡与打磨 | 动态难度（2人血×1.6/伤×1.15/金币×1.25，Boss 额外+10%血）、情绪节奏（3 分钟首掉、5-8 分钟精英、10-15 分钟 Boss） | S7 | 同上 + 全流程 smoke |
| P1 | 局域网联机 | Host 权威 UDP 同步位置/攻击/掉落；房间码/局域网列表 | S8 | EA 前补，不阻塞 MVP |

## 4. 门禁规则（硬约束）

1. **基座不可改**：`game/js/core.js`、`game/js/main.js`、`game/index.html`、`game/tests/game_logic.test.mjs`、`game/tests/smoke.mjs` 不得覆盖或修改。
2. **代码角色写入范围**：仅 `game/js/gameplay/` 或 `game/js/ui/` 下的增量 `.js` 模块。
3. **QA 写入范围**：仅新增 `game/tests/qa_*.mjs`。
4. **每切片必过**：`node --test game/tests/game_logic.test.mjs` 与 `node game/tests/smoke.mjs` 均通过，否则切片不通过。
5. **禁止**：生成 Python Web 服务、Flask、React 工程、Unity/Godot 代码；不得写项目目录之外；不得写密钥。
6. **裁决**：门禁结论由外部裁判/确定性工具给出，pm 只组装决策包与执行裁决，不批准、不驳回、不改裁判结论。

## 6. 升级与失败处理

- 同一决策最多 3 次；超时失败关闭并重试 1 次，仍失败置 BLOCKED。
- 触发升级：裁判超时、裁判 abstain、输入哈希变化、连续 3 次拒绝/补证。
- 耗尽后：置 BLOCKED，生成策略所有者决策包，**不默认通过**。

## 7. 里程碑

| 里程碑 | 切片 | 目标 |

| M0 原型 | S0-S3 | 横版战斗 + 房间门 + 掉落可玩 |

## 8. 验收指标（对齐需求第 12 节）

- 新手 10 分钟内获第一件蓝装；30 分钟内击败首个精英/Boss。
- 单局 15-30 分钟；全流程 15-25 小时。
- 崩溃率 <0.5%；读档成功率 >99.5%。
- 单人通关率 >35%；本地多人使用率 >25%。
