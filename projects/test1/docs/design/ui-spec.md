# 迷宫冒险家 · UI/UX 设计规范（v1）

> 角色：ui ｜ 依据：docs/product/product-baseline.md、docs/plan/project-plan.md
> 约束：不改变产品功能与核心流程；不修改技术实现与接口契约；所有设计可落地到 Canvas 绘制与 game/css。
> 基准分辨率：1280×720（16:9），整数倍缩放；低配 60fps 目标。

---

## 1. 设计原则

1. **单人优先**：所有界面在单人下信息完整；多人只做“增量叠加”（队友血条、复活提示），不隐藏单人内容。
2. **4399 怀旧感**：像素/卡通、粗描边、高饱和品质色、掉落光柱，一眼看懂“掉了个好东西”。
3. **低门槛**：任何面板 ≤2 次输入可达；关键操作有文字+图标双编码。
4. **短会话友好**：随时可读的状态（血蓝、金币、小地图、任务目标）常驻 HUD。
5. **可落地**：所有尺寸/颜色/时长以 Token 表达，Canvas 与 CSS 共用同一套值。

## 2. 信息架构（IA）

```
主界面 (Title)
├─ 继续 (Continue)            → 读最近存档槽
├─ 新游戏 (New Game)          → 选槽 → 选职业 → 教学
├─ 多人 (Multiplayer)
│   ├─ 本地同屏 (Local Co-op)  → 手柄A/键盘加入
│   └─ 局域网 (LAN) [P1]       → 房间码/列表
├─ 设置 (Settings)            → 画面/音频/操作/辅助
└─ 退出 (Quit)

游戏内 (In-Game)
├─ HUD（常驻）
│   ├─ 左上：血条/蓝条/等级
│   ├─ 左下：技能CD ×2 + 药水
│   ├─ 右上：小地图 + 房间类型图标
│   ├─ 右下：金币/材料
│   └─ 右侧：队友血条（多人时）
├─ 背包 (Inventory, Tab/I)
│   ├─ 装备 5 部位 + 背包 60 格
│   ├─ 对比箭头 / 一键分解白绿
│   └─ 强化 / 重铸入口
├─ 地图 (Map, M)
├─ 商店 (Shop) / 篝火 (Campfire) / 事件 (Event)
├─ 暂停 (Esc) → 继续/设置/回城/退出
└─ 结算 (Result) → 掉落清单 → 回城
```

## 3. 关键交互流程

### 3.1 新游戏 → 教学 → 首局
1. 主界面 → 新游戏 → 选存档槽（3 槽，显示等级/章节/时间）→ 选职业（剑士/法师/游侠，卡片含定位与单人友好度）。
2. 进入第一章第 1 层，触发 10 分钟新手引导（见 §8）。
3. 首次掉落蓝装时，弹出“品质光柱 + 拾取提示”，HUD 高亮背包图标 3 秒。

### 3.2 房间循环
- 进房间：小地图更新 → 门锁图标（战斗房）→ 清怪后门解锁动画（0.3s）。
- 篝火：回血/存档/复活队友/回城，四按钮竖排，主按钮高亮。
- Boss 前：自动存档提示条（顶部 2s）。

### 3.3 本地同屏加入
- 主界面或暂停菜单选“本地同屏” → 提示“按手柄 A / 键盘 Enter 加入” → 加入者显示职业选择 → 共享镜头，掉队 3s 传送（屏幕边缘箭头提示）。

### 3.4 结算
- Boss 死亡 → 结算面板：掉落清单（品质色）、金币、经验条动画 → “回城”主按钮。

## 4. 视觉规范（像素/卡通）

- **网格**：16px 基准网格；UI 元素对齐 8px 子网格；缩放 2x/3x 整数倍，禁用非整数缩放。
- **描边**：角色/图标 1px 深色描边（#1A1420），面板 2px 描边。
- **受击反馈**：闪白 80ms + 顿帧 80ms + 轻震（可关闭）。
- **掉落光柱**：品质色竖向渐变光柱，宽 12px，高 64px，呼吸 1.2s。
- **字体**：像素字体优先（位图），占位用等宽系统字体；中文用 12/14/16/20/28 阶梯。
- **图标**：24×24 像素图标，统一 1px 描边，禁用抗锯齿模糊。

## 6. HUD 布局标注（1280×720）

- 安全区：四周 24px。
- 左上（24,24）：血条 220×18，蓝条 220×12（血条下 4px），等级徽章 32×32 左侧。
- 左下（24, 720-24-64）：技能槽 2×48×48（间距 8），药水槽 48×48。
- 右上（1280-24-160, 24）：小地图 160×120，房间类型图标 16×16 叠加。
- 右下（1280-24-140, 720-24-28）：金币图标 24 + 数字。
- 右侧队友血条（多人）：x=1280-24-220，从 y=160 起竖排，每条 220×14，间距 8，最多 3 条（主机自身不重复）。
- 顶部提示条：居中，宽 480，高 32，2s 自动消失。

## 7. 面板规范

### 7.1 背包
- 左：装备 5 部位（64×64 槽，品质描边）；右：60 格网格（6×10，48×48，间距 4）。
- 悬停：Tooltip 显示词条、对比箭头（↑绿/↓红/＝灰）。
- 底部按钮：一键分解白绿（二次确认）、强化、重铸。

### 7.2 地图
- 房间节点 24×24，已探索实心、未探索虚线；Boss 房红色骷髅、篝火橙色火焰、商店金色袋。

### 7.3 商店 / 篝火 / 事件
- 统一面板 640×480，标题栏 48px，内容区滚动，底部主按钮右对齐。

### 7.4 多人面板
- 本地同屏：加入提示 + 玩家列表（职业色点 + 名字）。
- 局域网 [P1]：房间码输入框 + 局域网列表（低保真线框，本期不细化）。

## 9. 可访问性与低配降级

- 设置项：关闭屏幕震动、减少粒子、色盲友好品质图标（形状辅助：白圆/绿方/蓝菱/紫星/橙冠）。
- 文字对比度 ≥ 4.5:1（主文字/背景）。
- 低配：关闭光柱呼吸动画，保留静态品质色。

---

## 10. 落地说明

- Token 同时以 CSS 变量写入 `game/css/tokens.css`（增量），Canvas 侧读取同一常量表。
- 所有面板尺寸基于 1280×720，按整数倍缩放适配窗口。
- 本规范不新增/删减产品功能，仅定义呈现与交互；实现细节由架构/前端确认。
