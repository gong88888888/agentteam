# 迷宫冒险家 · 第一章威胁模型（Threat Model）

> 角色：security。上游：docs/plan/project-plan.md、docs/product/product-baseline.md、docs/architecture/architecture.md、contracts/openapi.yaml、tests/test-plan.md、docs/qa/findings.md。
> 交付物：可运行游戏，入口 game/index.html；技术栈 HTML5 Canvas + 原生 ES Modules，离线单机。
> 本文只做威胁建模与风险登记，不修改业务代码、不放宽红线、不签发门禁结论。
> 证据声明：本次未运行 semgrep/trivy/secret-scan，无产物 sha256，故所有结论为分析性判断，不计为证据。

---

## 0. 系统画像与攻击面

| 维度 | 事实 | 安全含义 |
|---|---|---|
| 部署形态 | PC Windows 本地运行，离线优先，无强制联网 | 无公网服务端攻击面；无账号/支付/遥测 |
| 技术栈 | HTML5 Canvas + 原生 ES Modules，无构建步骤 | 无 npm 依赖则供应链风险低；若有 CDN 资源则引入外部信任 |
| 数据 | JSON/SQLite 存档（本地），ScriptableObject/配置为静态数据 | 存档是唯一持久化资产，完整性优先于机密性 |
| 多人 | MVP 本地同屏 2 人（单进程）；局域网 2-4 人为 P1（Host-Client，UDP） | 本地同屏无信任边界；局域网引入“客机不可信”边界 |
| 付费 | 买断制，无内购、无交易行 | 无经济欺诈动机的外部攻击者，作弊仅影响自身体验 |

**信任边界**

1. TB-1 进程内：gameplay 纯逻辑与 ui 表现同进程，视为可信；边界在于“ui 不得写 gameplay 状态”（架构不变量，非安全边界）。
2. TB-2 本地存档文件：**不可信输入**。可能被用户编辑、被异常退出截断、被磁盘错误损坏。
3. TB-3 局域网客机（P1）：**不可信输入**。客机发送的位置/攻击/掉落请求需 Host 校验。
4. TB-4 外部资源（若存在 CDN/字体/音频）：不可信供应链。

## 1. 资产清单

| 资产 | 敏感度 | 说明 |
|---|---|---|
| A-1 世界存档（3 槽） | 完整性高 | 章节/层数/种子/已探索房间/Boss 状态/背包/金币/任务 |
| A-2 客机角色档 | 完整性高 | 背包/等级/装备，独立于主机世界 |

| A-4 本地设置 | 低 | 音量/键位/画质 |
| A-5 玩家隐私 | 低 | 无账号、无遥测、无支付，仅本地数据 |

## 2. STRIDE 分析

### 2.1 存档系统（TB-2）

| 类别 | 威胁 | 影响 | 现有设计 | 残余风险 |
|---|---|---|---|---|
| Tampering | 用户手改存档 JSON 提升金币/装备 | 仅影响自身体验（单机买断） | 无签名 | 接受（见 R-04） |
| Tampering | 存档被截断/位翻转 | 丢档、崩溃 | 双备份 + CRC 校验 + 版本迁移 | **需验证**（R-01） |
| Repudiation | 无（单机无审计需求） | — | — | 接受 |
| Information Disclosure | 存档含本地路径/设置 | 低 | 无敏感字段 | 接受 |
| Denial of Service | 损坏存档导致启动崩溃 | 无法进入游戏 | 损坏槽标记不可用，不阻塞其他槽 | **需验证**（R-01） |
| Elevation | 存档槽 ID 路径穿越（如 `../../`） | 越界写文件 | 槽 ID 应为白名单 1-3 | **需验证**（R-06） |

### 2.2 本地同屏多人（单进程）

| 类别 | 威胁 | 影响 | 缓解 |
|---|---|---|---|
| Tampering | 玩家 2 修改玩家 1 掉落 | 体验问题 | 独立掉落（每人只见自己光柱），逻辑层按 playerId 隔离 |
| DoS | 掉队/镜头拉扯导致卡死 | 体验 | 3 秒自动传送，共享镜头自动缩放 |
| 信息泄露 | 无 | — | — |

本地同屏无信任边界，不构成安全高危；仅作为体验健壮性项。

### 2.3 局域网联机（P1，TB-3）

| 类别 | 威胁 | 影响 | 缓解（P1 前置条件） |
|---|---|---|---|
| Spoofing | 伪造客机身份加入 | 干扰对局 | 房间码一次性 + 短时效；加入需 Host 确认 |
| Tampering | 客机发送超范围伤害/瞬移/刷装备 | 破坏对局 | Host 权威：位置/伤害/掉落由 Host 计算，客机仅发意图 |
| DoS | 恶意 UDP 洪泛/畸形包 | Host 卡死 | 包长与字段范围校验，异常包丢弃并限速 |
| Info Disclosure | 局域网广播泄露房间信息 | 低 | 仅广播房间码与人数，不含存档内容 |
| Elevation | 客机请求写主机世界存档 | 丢档 | 客机**不得**写主机世界档；仅 Host 落盘 |

> 结论：局域网为 P1，**不纳入 MVP 门禁**；但上述缓解必须作为 P1 开工前置条件写入计划，否则 P1 不得合入。

### 2.4 依赖与供应链（TB-4）

| 类别 | 威胁 | 影响 | 缓解 |
|---|---|---|---|
| Tampering | CDN 脚本/字体被替换 | 任意代码执行 | 优先零外部依赖；若必须，固定版本 + SRI + 本地托管 |
| Tampering | 依赖投毒（若引入 npm） | 高 | 锁文件 + 依赖清单 + trivy/审计 |
| Info Disclosure | 第三方资源回传 | 隐私 | 离线优先，禁止运行时外联 |

> 当前模板未声明依赖清单，**无法执行依赖扫描**，列为 R-03。

### 2.5 密钥与凭据

| 类别 | 威胁 | 影响 | 缓解 |
|---|---|---|---|
| Info Disclosure | 明文密钥/令牌入库 | 高 | 本项目无服务端、无账号、无支付，**不应存在任何密钥**；提交前 secret-scan |

> 若后续接入 Steam Cloud/远程同乐，需重新评审凭据管理。

## 3. 风险登记（按严重度）

| ID | 风险 | 等级 | 状态 | 缓解措施 | 验证方式 |
|---|---|---|---|---|---|
| R-01 | 存档双备份+CRC+版本迁移未落盘验证，读档成功率>99.5% 无证据 | **高** | 未关闭 | save.js 实现 CRC 校验、双备份轮换、损坏回退最近篝火、版本迁移；损坏槽隔离不阻塞启动 | `node --test game/tests/qa_save.mjs`（CRC 损坏回退用例）+ 人工注入损坏存档验证回退 |
| R-02 | frontend 产物路径违规 `src/frontend/game/js/ui/hud.js`，不在 `game/js/ui/`，ESM 无法加载 | **高** | 未关闭 | 迁移至 `game/js/ui/hud.js` 并修正 import；核对与 arch 模块表一致 | 人工确认文件存在 + `node game/tests/smoke.mjs` 通过 + 浏览器加载无 404 |
| R-03 | 无依赖清单/无扫描证据，供应链与投毒不可评估 | **高** | 未关闭 | 声明零外部依赖或提供锁文件；执行 trivy/secret-scan 并留存签名结果 | 依赖清单存在性检查 + 扫描器输出（需签名） |
| R-04 | 本地存档可被用户篡改（金币/装备） | 中 | 接受 | 单机买断无经济外部循环，不设反作弊；仅保证篡改后不崩溃 | 畸形存档注入测试不崩溃 |
| R-05 | 局域网客机不可信（P1） | 中 | P1 前置 | Host 权威 + 输入范围校验 + 客机不写主机档 + 房间码短时效 | P1 开工前补威胁用例 |
| R-06 | 存档槽 ID 路径穿越 | 低 | 待验证 | 槽 ID 白名单 1-3，拒绝其他输入 | 单元测试非法槽 ID 被拒 |
| R-07 | 隐私：无账号/遥测/支付，仅本地数据 | 低 | 接受 | 不采集、不外联 | 代码审查无网络请求 |
| R-08 | 配置数据被改影响平衡 | 低 | 接受 | 静态只读，不影响安全 | — |

**红线（一票否决）**：R-01、R-02、R-03 未关闭前，第一章不得发布；扫描器不可用时失败关闭，不默认通过。

## 4. 合规检查

| 项 | 结论 |
|---|---|
| 个人信息保护 | 无账号、无遥测、无支付，不采集 PII；仅本地设置与存档，合规风险低 |
| 未成年人保护 | 买断制无内购、无抽卡付费，无诱导消费 |
| 内容合规 | 卡通打怪，无血腥写实；上线前按发行地区做内容分级 |
| 开源许可 | 若引入第三方资源需登记许可证；当前无依赖清单，待补 |
| 数据出境 | 无云端数据，不涉及 |

## 5. 验证清单（合并前必须执行）

```
node --test game/tests/game_logic.test.mjs   # 基线，不得修改
node game/tests/smoke.mjs                    # 基线，不得修改
node --test game/tests/qa_save.mjs           # R-01 存档完整性
node --test game/tests/qa_loot.mjs           # 掉落/强化不变量
node --test game/tests/qa_coop.mjs           # 缩放/扶起（P1 前）
```

人工项：
1. 确认 `game/js/ui/hud.js` 存在且被 index.html 正确加载（R-02）。
2. 注入截断/位翻转存档，确认回退最近篝火且不崩溃（R-01）。
3. 确认仓库无密钥/令牌（secret-scan 或人工 grep）。
4. 确认无运行时外部网络请求（离线优先）。
