# 迷宫冒险家 · 威胁模型（Security Threat Model）

> 角色：security · 阶段：设计/实现前 · 结论：设计阶段威胁模型，未运行扫描器，不构成门禁通过证据。

## 1. 范围与系统边界

| 项 | 说明 |
|---|---|
| 交付形态 | 离线 PC 游戏，入口 `game/index.html`，HTML5 Canvas + 原生 ES Modules |
| 运行环境 | 本地浏览器/本地运行器，无强制联网，无 Web 后端 |
| 数据 | 本地存档（角色/世界/背包/种子）、配置（装备/怪物 JSON） |
| 多人 | MVP：单人 + 本地同屏 2 人；P1：局域网 2-4 人（主机权威） |
| 非目标 | 账号系统、支付、云存档、交易行、远程同乐（均不在 MVP） |

## 2. 资产识别

| 资产 | 敏感度 | 说明 |
|---|---|---|
| A1 存档数据 | 高 | 角色属性、背包、装备、金币、任务、地图种子、Boss 状态；丢失=用户核心损失 |
| A2 世界进度 | 高 | 主机世界槽，多人共享 |
| A3 配置数据 | 中 | 装备/怪物/掉落表，被篡改影响平衡与公平 |
| A4 输入事件 | 中 | 键盘/手柄/客机网络输入 |
| A5 构建产物 | 中 | 增量 JS 模块与依赖 |
| A6 用户本机 | 高 | 文件系统写入范围 |

## 3. 信任边界

1. **单机离线**：本地进程完全可信；威胁来自存档损坏、恶意篡改存档、构建产物被替换。
2. **本地同屏**：同机可信，但输入不可信（手柄/键盘事件可能异常或高频）；掉落独立分桶防抢。
3. **局域网 P1**：主机权威，**客机不可信**；客机输入必须主机校验（位置/攻击/掉落请求），客机不得直接写主机世界状态。
4. **存档介质**：浏览器 localStorage/IndexedDB 为不可信介质（可被用户或扩展修改），读取必须校验。

## 4. 威胁清单（STRIDE 精简）

### 4.1 存档完整性（高危）
- **T1 存档损坏/截断**：异常退出导致半写。缓解：SaveEnvelope 版本号 + CRC32 + 双备份 + 原子写（先写临时再替换）；读取失败回退备份，双份均失败回最近篝火快照。验证：QA `qa_save_envelope` 覆盖截断、CRC 错误、双备份回退。
- **T2 存档篡改**：用户手改金币/装备。缓解：CRC 校验失败拒绝加载并提示；单机不追求防作弊，但拒绝静默接受损坏数据。验证：篡改字节后加载应报错而非崩溃。
- **T3 版本不兼容**：旧档新版本加载。缓解：版本号 + 迁移链；迁移失败保留原档只读。验证：版本不匹配用例。

### 4.2 多人信任边界（P1，高危）
- **T4 客机越权写主机状态**：客机伪造掉落/金币/位置。缓解：主机权威，客机仅发意图，主机校验并广播结果；客机不得调用主机世界写接口。验证：契约评审 + 联机后渗透用例（P1 阶段）。
- **T5 输入洪泛/异常输入**：高频或畸形输入导致卡死。缓解：输入限频、字段类型与范围校验、固定步长 tick 丢弃超量输入。验证：QA 战斗 tick 用例 + 输入边界用例。
- **T6 掉落抢夺**：多人共享掉落被抢。缓解：装备按玩家 id 哈希独立分桶，金币材料共享。验证：QA `qa_loot_bucket`。

### 4.3 渲染与注入（中）
- **T7 DOM 注入**：增量 UI 模块用 innerHTML 拼接外部/存档文本（角色名、装备名）。缓解：禁止 innerHTML 拼接动态数据，使用 textContent；禁止 eval/new Function。验证：集成后静态扫描（semgrep 规则）+ 代码评审。
- **T8 恶意配置**：被替换的装备/怪物 JSON 注入脚本或超范围数值。缓解：配置仅作数据解析（JSON.parse），数值做范围钳制；不执行配置中的任何代码。验证：畸形配置用例。

### 4.4 文件系统（中）
- **T9 路径穿越写盘**：存档/日志路径由外部输入拼接。缓解：写盘路径白名单（仅存档目录），文件名由固定模板生成，不拼接用户输入。验证：代码评审 + 路径用例。

### 4.5 供应链（中）
- **T10 依赖投毒**：第三方库被替换。缓解：锁定版本、离线优先、运行时不远程加载脚本、构建产物网络请求审计。验证：构建产物网络请求审计 + 依赖清单核对。
- **T11 明文密钥**：仓库出现凭据。缓解：本项目无服务端、无密钥需求；禁止提交任何 token/密钥。验证：secret-scan（当前不可用，列为待补）。

## 5. 高危一票否决清单

以下任一出现即 BLOCKED，禁止发布：
1. 存档无校验或单份存储导致可复现丢档。
2. 客机可写主机世界状态（P1）。
3. 明文密钥/凭据入库。
4. 依赖投毒或运行时远程加载可执行脚本。
5. 路径穿越写盘。

## 7. 合规与隐私

- 无账号、无遥测、无联网上传，MVP 不采集个人数据。
- 本地存档仅存游戏数据，不含设备标识。
- 买断制无内购，无支付合规面。

## 8. 失败处理

- 扫描器不可用：失败关闭，不默认通过，不声明门禁通过。
- 出现高危项：置 BLOCKED，禁止发布，升级至 reviewer/judge。

## 9. 待办（open questions）
