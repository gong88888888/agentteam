# 迷宫冒险家 · 产品基准（Product Baseline）

> 角色：product ｜ 状态：基准草案 v1 ｜ 上游：docs/plan/project-plan.md（gate=pass）
> 本文件是范围与验收的唯一产品基准；变更需走变更流程，不得静默扩大范围。

---

## 1. 产品定位

**一句话**：一款适合下班后单人刷两层、朋友来了同屏打Boss的 PC 横版迷宫刷装游戏。

| 项 | 定义 |
|---|---|
| 项目代号 | 迷宫冒险家 |
| 平台 | PC Windows，本地运行，离线优先 |
| 付费 | 买断制，无内购；后续 DLC 加职业/章节 |
| 画面/视角 | 2D 横版卡通像素/手绘，房间制迷宫，门连接，地图随机生成 |
| 目标用户 | 20-40 岁，怀旧4399/冒险岛、轻肉鸽、刷装备、短会话、可单人可朋友同玩 |
| 会话时长 | 单局 15-30 分钟；单章 2-4 小时；全流程 15-25 小时 |
| 交付形态 | 可运行游戏，入口 `game/index.html`（HTML5 Canvas + 原生 ES Modules） |

**核心卖点（按优先级）**
1. 单人离线完整可通关：所有 Boss、装备、剧情单人均可获取。
2. 本地同屏 2-4 人 + 局域网 2-4 人，朋友来了就能玩。
3. 随机迷宫 + 固定章节 Boss + 装备词条，轻刷不肝。
4. 一键存档、角色独立存档、主机世界存档，防丢档。

**第一优先级原则**：单人模式是基准平衡与完整内容载体；多人只做动态缩放与协作增强，**不设计必须多人才能开的门/机关/剧情**。

---

## 2. 目标用户与场景

| 用户 | 需求 | 设计回应 |
|---|---|---|
| 怀旧玩家 | 冒险岛式横版打怪、掉装、跳台 | 横版房间、平台跳跃、装备品质光柱 |
| 轻中度上班族 | 时间碎、不想重度社交 | 单局 15-30 分钟，随时存档，单人完整 |
| 朋友同玩 | 本地/局域网低门槛 | 本地同屏、手柄/键盘混用、无服务器 |
| 刷装玩家 | 词条、品质、Boss 掉落 | 5 品质、词条重铸、图鉴 |
| 手残/休闲 | 不想被高难度卡 | 三档难度、动态人数缩放、复活币 |

**典型场景**
- S1 下班单人：回城整备 → 选层 → 8-12 房间 → 精英/Boss → 结算 → 强化换装 → 下线（15-30 分钟）。
- S2 朋友到家：主机开本地同屏，手柄 A 加入，共享镜头，装备独立掉落，倒地互扶。
- S3 同网联机（P1）：主机建房，客机加入，主机权威，客机角色独立存档。
- S4 手残玩家：低难度 + 复活币 + 篝火回血，仍可通关第一章。

---

## 3. 核心循环与情绪节奏

- **单局循环**：回城整备 → 选迷宫层/章节 → 探索 8-12 房间 → 打怪掉装/金币/材料 → 事件房/商店/篝火 → 精英/Boss → 结算 → 回城分解/强化/换装 → 下一层。
- **长期循环**：推章节 → 解锁难度/新词条 → 刷 Boss 套装 → 委托/图鉴 → 深层迷宫 → 多职业体验。
- **情绪节奏**：前 3 分钟首次掉落；5-8 分钟精英怪；10-15 分钟 Boss；回城给明确成长。避免“刷半天没提升”。

---

## 4. 模式矩阵与多人规则

| 模式 | 人数 | 范围 |
|---|---|---|
| 单人离线 | 1 | MVP（完整剧情/掉落/Boss/存档） |
| 本地同屏 | 2-4（MVP 先 2） | MVP（共享镜头，键鼠+手柄混用，掉落独立） |
| 局域网联机 | 2-4 | P1（EA 前补，主机权威） |
| 远程同乐 | P2 | 非目标（后续可选） |

**多人规则（设计基准）**
- 动态难度（以单人为基准）：2 人 血量×1.6/伤害×1.15/金币×1.25；3 人 ×2.1/×1.25/×1.45；4 人 ×2.6/×1.35/×1.65；Boss 额外 +10% 血量。
- 掉落：金币/材料共享拾取；装备独立掉落，各自光柱，防抢。
- 复活：单人死亡回篝火/消耗复活币；多人倒地可被队友 3 秒扶起，全员倒地回城。
- 存档归属：主机保存世界进度；客机保存自身角色背包/等级/装备；客机加入按主机世界难度校验。
- 单人切换：任何多人存档均可由主机切回单人继续，不锁内容。

## 5. 功能清单（含范围标注）

标注：**MVP** = 12 周内交付；**P1** = EA 前；**EA/正式** = 后续。

### 5.1 迷宫
- MVP：每层 8-12 房间 + 1 Boss 房；房间类型含战斗/平台跳跃/宝箱/商店/篝火/事件/精英/Boss；房间模板+门连接+关键路径生成，保证入口到 Boss 主路径；每层固定 1 篝火 1 商店，精英房 60%，宝箱房 2-4；钥匙门每层最多 1 且钥匙由精英/事件给，避免卡死；记录随机种子与已探索房间，读档可恢复。
- MVP：第一章“蘑菇林迷宫”5 层（教学 + 首个 Boss）。
- EA：第二/三章各 5 层、无尽迷宫。

### 5.2 战斗与职业
- MVP：3 职业（剑士/法师/游侠），操作含移动/跳跃/普攻/重击/闪避/2 技能/喝药/交互，键鼠+手柄混用。
- MVP：20 种怪（近战冲撞/远程投掷/飞行/自爆 + 精英词缀），1 个三阶段 Boss，明确前摇。
- MVP：打击感（受击闪白、顿帧 80ms、轻震、掉落光柱、音效分层），低配保证。
- EA：更多 Boss/怪/职业。

### 5.3 装备与经济
- MVP：5 部位（武器/头盔/衣服/鞋子/饰品），武器职业独立、防具通用；5 品质（白/绿/蓝/紫/橙），权重 40/30/20/8/2，Boss 保底蓝、紫 20%、橙 5%；2-4 条词条；背包 60 格、仓库 200 格；分解、强化 +1~+9（失败不掉级）、重铸（保底）；金币来源与消耗闭环，单机不做交易行。
- MVP：50 件装备。
- EA：词条池扩充、套装、图鉴加成。

### 5.4 成长与任务
- MVP：角色 1-30 级，属性自动分配、技能点手动；主线引导打 Boss；委托板 3 个日常。
- EA：图鉴、成就、深层挑战。

### 5.5 存档
- MVP：3 个世界槽；自动存档（进房间/回城/Boss 前/篝火），手动仅篝火/回城；存档含角色属性/背包/装备/金币/任务/地图种子/已开房间/Boss 状态/设置；双备份 + CRC 校验；异常退出回最近篝火；版本号 + 自动迁移。
- 非目标：云存档（MVP 不做）。

### 5.6 UI/UX
- MVP：主界面（继续/新游戏/多人/设置/退出）、HUD（血蓝/技能 CD/金币/小地图/队友血条）、背包（品质色/对比箭头/一键分解白绿）、地图（已探索/Boss/篝火）、10 分钟新手引导（移动/打怪/捡装/回城/存档）。
- P1：局域网房间码/列表、本地同屏手柄 A 加入。

## 6. 非目标清单（明确不做，防止范围蔓延）

1. 不做交易行、拍卖行、玩家间经济。
2. 不做云存档（MVP 与 EA 初期均不做）。
3. 不做远程同乐（P2，不纳入 MVP/EA 承诺）。
4. 不做人数专属门/机关/剧情，不做“必须多人才能通关”的内容。
5. 不做内购、抽卡、体力、在线服务端。
6. 不做重度社交（公会、语音、匹配大厅）。
7. 不做 Web 后端/React 后台/Unity/Godot 工程；交付形态固定为 `game/index.html` + Canvas + 原生 ES Modules。
8. 不做移动端/主机端适配。
9. 不以“用户可能需要”为理由新增未列功能；新增须走变更流程。

## 7. 验收标准（可量化）

### 7.1 体验指标
- 新手 10 分钟内获得第一件蓝装；30 分钟内击败首个精英/Boss。
- 单局 15-30 分钟；全流程 15-25 小时（正式版口径，MVP 只验第一章时长 2-4 小时）。
- 单人通关率目标 >35%；本地多人使用率 >25%（上线后观测，非 MVP 门禁）。

### 7.2 稳定性指标
- 崩溃率 <0.5%；读档成功率 >99.5%。
- 房间加载 <2 秒；GTX750/集显 60 帧。

### 7.3 工程门禁（MVP 必须通过）
- `game/index.html` 可运行，单人可完成第一章 5 层并击败首个 Boss。
- `node --test game/tests/game_logic.test.mjs` 通过。
- `node game/tests/smoke.mjs` 通过。
- 代码仅新增 `game/js/gameplay/`、`game/js/ui/` 增量模块；QA 仅新增 `game/tests/qa_*.mjs`；不修改基座文件。

### 7.4 功能验收（MVP 逐项可验）
- 迷宫：每层 8-12 房间 + Boss 房，主路径可达，钥匙门不卡死，读档恢复种子与已探索房间。
- 战斗：3 职业可玩，20 怪与 1 三阶段 Boss 可击败，打击感要素生效。
- 装备：5 品质掉落权重生效，Boss 保底蓝，词条 2-4 条，强化/重铸/分解可用。
- 存档：3 槽位、自动存档点、双备份 + CRC、异常退出回篝火、版本迁移。
- 多人（本地双人）：共享镜头、装备独立掉落、倒地互扶、主机存档归属。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 多人平衡 | 单人基准 + 动态缩放；所有 Boss 单人可打 |
| 内容量不足 | 房间模板组合 + 词条 + 无尽层（EA） |
| 存档兼容 | 版本迁移 + 双备份 + CRC |
| 同屏镜头 | 共享镜头 + 靠近自动缩放，掉队 3 秒传送 |
| 刷装枯燥 | 保底掉落 + 委托 + 图鉴 + 重铸 |

## 9. 待确认问题（open questions）

1. 多人动态缩放数值需在 MVP 本地双人实测后校准，当前为设计基准。
2. 橙装 2% / Boss 橙 5% 是否 MVP 直接生效，或先降档缩短验证周期，需与 pm 确认。
3. MVP 仅本地同屏时，客机角色是否仍需独立档位，或简化为同槽位角色，需与 arch 确认。
4. 无尽迷宫/图鉴/成就属 EA 范围，MVP 验收不覆盖，需确认基准中标注为“非 MVP 验收项”。
