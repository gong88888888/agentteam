## 1. 项目定位（可复用一句话）

2D 横版房间制迷宫动作冒险 + 轻刷装 + 本地同屏；单人离线为完整主模式，多人仅动态缩放增强，不是把单人内容阉割后加联机。

硬约束（红线，任何后续设计不得违反）
1. 单人模式是平衡基准；所有 Boss / 装备 / 剧情单人可获取。
2. 不设必须多人才能开的门 / 机关 / 专属剧情。
3. 多人只做动态缩放 + 协作（扶起、独立掉落），不新增单人不可达内容。
4. 买断制，无内购；MVP 不做交易行 / 云存档 / 远程同乐。

## 2. 可复用设计资产（数值口径，直接可抄）

### 2.1 多人动态缩放（以单人基准）

| 人数 | 怪物血量 | 怪物伤害 | 掉落金币 |
|---|---|---|---|
| 2 | x1.6 | x1.15 | x1.25 |
| 3 | x2.1 | x1.25 | x1.45 |
| 4 | x2.6 | x1.35 | x1.65 |

- Boss 额外 +10% 血量。
- 复活：单人回篝火/消耗复活币；多人倒地可被队友 3 秒扶起，全员倒地回城。
- 掉队（同屏）：3 秒自动传送到队友身边。

### 2.2 房间生成不变量（可测试契约）

1. 同 seed + 同层号 -> 完全相同的房间图（确定性）。
2. 房间数属于 [8,12]，另有 1 个 Boss 房。
3. 入口到 Boss 存在主路径（连通性检查通过）。
4. 每层恰好 1 个篝火房、1 个商店房。
5. 宝箱房属于 [2,4]；精英房概率 60%（由 seed 决定）。
6. 钥匙门 <=1，且无钥匙时主路径仍可达 Boss（钥匙门只锁支路，防卡死）。

### 2.3 装备与掉落

- 5 部位：武器 / 头盔 / 衣服 / 鞋子 / 饰品；每职业武器独立，防具通用。
- 5 品质权重：白 40% / 绿 30% / 蓝 20% / 紫 8% / 橙 2%。
- Boss 保底蓝，紫 20%、橙 5%。
- 词条 2-4 条（攻击/暴击/攻速/生命/移速/技能冷却/金币获取）。
- 强化 +1~+9，失败不掉级只耗材料；重铸随机 1 条词条且有保底。
- 背包 60 格 / 仓库 200 格；装备可分解为材料。

### 2.4 存档

- 3 个世界槽；每槽含世界进度 + 主机角色；客机角色单独档。
- 自动存档点：进房间、回城、Boss 前、篝火；手动存档仅篝火/回城。
- 防丢档：双备份 + CRC 校验；异常退出回最近篝火。
- 版本兼容：存档带版本号，升级自动迁移；客机版本不匹配只读提示。

### 2.5 战斗手感基线

受击闪白、顿帧 80ms、屏幕轻震、掉落光柱、音效分层；低配也保证。

## 3. 关键决策记录（ADR 摘要，可复用）

| 编号 | 决策 | 理由 | 后果 |
|---|---|---|---|
| D-01 | HTML5 Canvas 2D + 原生 ESM，无构建步骤 | 符合不重写引擎约束，浏览器直接加载 | 发布即目录快照+校验，不引入打包器 |
| D-02 | 逻辑层 game/js/gameplay/ 纯函数、无副作用导入（不访问 window/document），随机数用注入 seed 的 PRNG | 使 node --test 可无浏览器测试 | gameplay 不得 import ui；ui 只读 + 派发意图事件 |
| D-03 | 表现层 game/js/ui/ 只读逻辑状态渲染，不反向改逻辑 | 逻辑/渲染解耦 | ui 不得写 gameplay 状态 |
| D-04 | 局域网 Host 权威，UDP 同步位置/攻击/掉落 | 低门槛联机 | 客机加入按主机世界难度校验；P1 范围 |
| D-05 | 发布门禁 = 基线两条命令 + qa_*.mjs + 路径违规修复 + 存档往返/CRC 用例 | 失败关闭，不默认通过 | 缺一即 BLOCKED 并保留现场 |

## 4. 踩坑与已知阻断（失效条件，务必先核对）

以下为已知风险/阻断，不是已修复事实；引用本知识前必须先验证其是否仍成立。

- K-01 交付路径违规：frontend 产物落在 src/frontend/game/js/ui/hud.js，不在 game/js/ui/，game/index.html 的 ESM 无法加载。需迁移到 game/js/ui/ 并核对 import 路径。
- K-02 gameplay 模块落盘未证实：mapgen/combat/items/loot/save/coop 等是否真实存在于 game/js/gameplay/ 未证实；qa_*.mjs 以契约纯函数为断言目标，模块缺失时应显式失败而非 skip 掩盖。
- K-03 无基线运行证据：无 game_logic.test.mjs / smoke.mjs 实际运行输出，读档成功率>99.5%、崩溃率<0.5% 无法量化。
- K-04 存档完整性未验证：双备份 + CRC + 版本迁移方案已定义但未跑通用例。
- K-05 路径穿越：存档槽 ID 需白名单 1-3，防止越界读写。
- K-06 局域网 P1 前置：Host 权威与加入码防爆破列为 P1 前置条件，未确认前不纳入 MVP。

## 5. 验收指标（可量化，供后续复用）

- 新手 10 分钟内获得第一件蓝装；30 分钟内击败首个精英/Boss。
- 单局 15-30 分钟；第一章 5 层合计 2-4 小时；全流程 15-25 小时。
- 崩溃率 <0.5%；读档成功率 >99.5%。
- 单人通关率 >35%；本地多人使用率 >25%。
- 主菜单到可操作 <=3 秒；房间加载 <2 秒；GTX750/集显 60 帧。

## 6. 复用指引

1. 新章节/新层：直接复用 2.2 房间生成不变量与 2.1 缩放口径，不改红线。
2. 新职业：复用 2.3 装备部位与品质权重，武器独立、防具通用。
3. 新 UI：复用 ui-spec 的 Design Token（品质色/间距/字号/层级/动效时长），多人元素仅在人数>=2 出现。
4. 发布前：先核对第 4 节阻断是否已解除，再跑基线两条命令 + qa_*.mjs，缺一 BLOCKED。
