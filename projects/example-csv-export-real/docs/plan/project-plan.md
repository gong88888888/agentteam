# MiniLedger CSV 导出项目计划

## 1. 项目概述
- **ID**: REQ-CSV
- **目标**: 允许用户按月份导出记账记录为 CSV，用于归档和分析。
- **非目标**: Excel公式、图表、多Sheet、定时/邮件导出、新服务引入。

## 2. 功能切片 (Slicing)

### Slice 1: 基础导出与权限校验 (S1)
- **任务**: 
  - 实现 `/export/csv` 接口，接收 `year` 和 `month` 参数。
  - 集成现有认证中间件，严格校验 `owner_id`。
  - 复用现有记录查询接口，过滤当前用户数据。
  - 生成 UTF-8 + BOM 编码的 CSV 文件。
  - 处理空数据月份（返回合法空 CSV）。
- **验收**: 
  - 正确导出指定月份数据。
  - 非 owner 请求被拒绝 (403)。
  - 空月不报错。

### Slice 2: 性能优化与边界处理 (S2)
- **任务**:
  - 实现流式写入或分批读取，确保单次导出 1 万行 P95 < 2s。
  - 增加数据量检查：超过 10 万行返回明确错误信息。
  - 优化查询索引（如需）。
- **验收**:
  - 性能指标达标。
  - 超限错误处理正确。

### Slice 3: 测试与文档 (S3)
- **任务**:
  - 编写单元测试：权限校验、空数据、大文件边界。
  - 编写集成测试：模拟不同用户导出场景。
  - 更新 API 文档。
- **验收**:
  - 测试覆盖率达标。
  - 文档清晰准确。

## 3. 依赖顺序
1. Slice 1 (基础功能)
2. Slice 2 (性能与边界)
3. Slice 3 (测试与文档)

## 4. 门禁与角色分工

| 阶段 | 门禁名称 | 负责角色 | 检查重点 |
|------|----------|----------|----------|
| 启动 | Product Gate | Product | 需求完整性、非目标明确性 |
| 设计 | Architecture Gate | Arch | 权限模型、性能方案、复用性 |
| 开发完成 | S1 Gate | Dev/S1 | 基础功能实现、权限校验 |
| 开发完成 | S2 Gate | Dev/S2 | 性能指标、边界处理 |
| 测试完成 | Acceptance Gate | QA/Test | 验收标准达成、空数据/超限场景 |
| 发布 | Release Gate | PM/Release | 文档、回滚计划 |

## 5. 风险与约束
- **约束**: 复用现有接口，不引入新服务。
- **风险**: 现有查询接口性能不足可能导致 P95 超标。需架构阶段评估并优化。
- **安全**: 严格的数据隔离是核心要求。
