# product · 产品基准（第一章 / MVP）

> 角色：product。本文是可验收的产品基准，不是功能清单。先写非目标，再写状态机流程，逐状态给输入、失败恢复与量化验收。
> 硬约束：单人离线完整可通关为第一优先级；所有 Boss/装备/剧情单人可达；多人仅动态缩放与协作，不设人数专属门/机关/剧情。

## 0. 一句话与范围

一句话：一款适合下班后单人刷两层、朋友来了同屏打 Boss 的 PC 横版房间制迷宫刷装游戏。

MVP 范围：第一章 5 层、3 职业、20 种怪、1 Boss、50 件装备、单人 + 本地同屏 2 人、存档、背包、强化、商店、篝火。

## 1. 非目标（明确不做，防止范围蔓延）

| 编号 | 非目标 | 理由 |
|---|---|---|
| NG-1 | 交易行 / 玩家间交易 | 单机买断，无经济外部性 |
| NG-2 | 云存档 / Steam Cloud | MVP 不做，后续可选 |
| NG-3 | 远程同乐 / 在线匹配 | 不纳入 MVP，局域网为 P1 |
| NG-4 | 人数专属门、机关、剧情、Boss 机制 | 违反“单人完整可通关”原则 |
| NG-5 | 反作弊 / 服务端权威 | 离线单机，仅保证不崩溃与存档可恢复 |
| NG-6 | 内购 / 付费点 / 广告 | 买断制 |
| NG-7 | 多周目继承、赛季、排行榜 | 非第一章验收所需 |
| NG-8 | 手柄热插拔的完整兼容矩阵 | MVP 仅保证启动前接入可用 |

## 2. 全局状态机（顶层）

状态：`BOOT → MAIN_MENU → CHAR_SETUP → RUN_LOADING → DUNGEON_LOOP → BOSS_ROOM → RESULT → TOWN → (回 MAIN_MENU 或下一层)`，旁路状态 `PAUSE`、`SAVE_LOAD`、`ERROR_RECOVERY`。

- 任一游戏内状态可进入 `PAUSE`；`PAUSE` 返回原状态。
- 任一状态发生不可恢复异常进入 `ERROR_RECOVERY`，回最近篝火或主菜单。
- 存档/读档为旁路，不改变当前状态机主链。

## 3. 逐状态定义

### S1 主菜单 MAIN_MENU
- 输入：继续（有存档时可用）、新游戏、多人、设置、退出。
- 转移：继续→RUN_LOADING（读最近存档）；新游戏→CHAR_SETUP；多人→CHAR_SETUP（本地同屏 2 人）。
- 失败恢复：无存档时“继续”置灰并提示“暂无存档”；存档 CRC 校验失败→提示“存档损坏，已回退备份”，加载备份槽。
- 验收：无存档时继续不可点；损坏存档可回退到备份且不崩溃。

### S2 选职业/难度 CHAR_SETUP
- 输入：职业（剑士/法师/游侠）、难度（简单/普通/困难）、本地同屏人数（1 或 2）、确认/返回。
- 转移：确认→RUN_LOADING；返回→MAIN_MENU。
- 失败恢复：未选职业时确认置灰；难度默认普通。
- 验收：三职业均可选；难度影响怪物伤害/血量系数且单人基准为“普通”。

### S3 层加载 RUN_LOADING
- 输入：无（自动）。
- 转移：加载完成→DUNGEON_LOOP（入口房间）。
- 失败恢复：加载超时（>5s）→提示“加载失败，重试/回主菜单”；地图种子缺失→用新种子重生成并提示。
- 验收：房间加载 <2s（目标）；种子记录于存档，读档可恢复已探索房间。

### S4 迷宫循环 DUNGEON_LOOP（8-12 房间 + 1 Boss 房）
- 房间类型：战斗、平台跳跃、宝箱、商店、篝火、事件、精英、Boss。
- 生成不变量：每层固定 1 篝火、1 商店；精英房概率 60%；宝箱房 2-4；钥匙门 ≤1 且钥匙由精英/事件给，避免卡死；入口到 Boss 必有主路径。
- 输入：移动、跳跃、普攻、重击、闪避、2 技能、喝药、交互（开门/开箱/对话）。
- 转移：清怪/交互开门→下一房间；进入 Boss 房→BOSS_ROOM；篝火快速回城→TOWN。
- 失败恢复：
  - 单人死亡→回最近篝火，消耗复活币（无币则回城并保留装备）。
  - 多人倒地→队友 3 秒内可扶起；全员倒地→回城。
  - 掉队（同屏）→3 秒自动传送到队友身边。
  - 卡死检测（无门可开且无怪）→提供“重置本层”按钮，保留已获装备。
- 验收：同种子生成确定；主路径连通；篝火/商店各 1；钥匙门 ≤1；单人可完成全部房间类型。

### S5 战斗与掉落（DUNGEON_LOOP 内子流程）
- 输入：攻击/技能/闪避/喝药。
- 规则：受击闪白、顿帧 80ms、屏幕轻震、掉落光柱；品质权重白 40/绿 30/蓝 20/紫 8/橙 2；Boss 保底蓝，紫 20%、橙 5%；装备 2-4 词条。
- 多人：金币/材料共享拾取；装备独立掉落，每人只见自己的光柱。
- 失败恢复：掉落生成异常→跳过该次掉落并记录日志，不阻塞开门。
- 验收：新手 10 分钟内获得首件蓝装；30 分钟内击败首个精英/Boss；掉落权重可被测试断言。

### S6 商店/篝火/事件
- 商店：买药、钥匙、随机装备；金币不足时购买置灰。
- 篝火：回血、存档、复活队友、快速回城。
- 事件：赌装备、诅咒/祝福、NPC 委托；选择后不可撤销，需二次确认。
- 失败恢复：商店/事件数据缺失→该房间降级为战斗房并提示。
- 验收：篝火可手动存档；商店金币扣减正确；事件二次确认生效。

### S7 Boss 房 BOSS_ROOM
- 输入：战斗操作。
- 规则：三阶段，明确前摇；多人血量额外 +10%；仇恨优先最近/伤害最高，不只追主机。
- 转移：击败→RESULT；全员倒地→回城（保留装备）。
- 失败恢复：Boss 卡阶段→超时 30s 强制进入下一阶段；Boss 房崩溃→回 Boss 前自动存档点。
- 验收：单人可击败 Boss；三阶段前摇可辨识；多人缩放系数正确。

### S8 结算 RESULT
- 输入：确认。
- 展示：获得装备/金币/材料、用时、击杀数。
- 转移：确认→TOWN。
- 失败恢复：结算数据缺失→显示“结算异常”，仍发放已拾取物品。
- 验收：结算物品与实际拾取一致。

### S9 回城 TOWN
- 输入：分解、强化、重铸、换装、接委托、进入下一层、回主菜单。
- 规则：背包 60 格、仓库 200 格；强化 +1~+9 失败不掉级但耗材料；重铸随机 1 条词条有保底。
- 失败恢复：背包满→提示并允许一键分解白绿。
- 验收：强化失败不掉级；重铸保底生效；一键分解白绿可用。

### S10 存档/读档 SAVE_LOAD（旁路）
- 触发：进房间、回城、Boss 前、篝火自动存档；手动存档仅篝火/回城。
- 内容：角色属性、背包、装备、金币、任务、地图种子、已开房间、Boss 状态、设置、版本号。
- 防丢档：双备份 + CRC 校验；异常退出回最近篝火。
- 失败恢复：CRC 失败→加载备份；版本不匹配→自动迁移，客机角色只读提示。
- 验收：读档成功率 >99.5%；损坏存档可回退备份；版本迁移不丢关键字段。

### S11 双人复活（多人子状态）
- 输入：靠近倒地队友 + 交互键持续 3 秒。
- 转移：扶起成功→队友恢复部分血量；3 秒内未扶起→队友回篝火。
- 失败恢复：扶起中断（受击/离开）→进度重置。
- 验收：单人模式下不出现扶起提示；2 人时扶起 3 秒生效；全员倒地回城。

### S12 暂停 PAUSE
- 输入：继续、设置、回主菜单（提示未存档进度）。
- 失败恢复：回主菜单前自动存档一次。

### S13 错误恢复 ERROR_RECOVERY
- 触发：未捕获异常、资源加载失败、存档损坏。
- 行为：提示 + 回最近篝火或主菜单；保留现场日志。
- 验收：不白屏、不丢档。

## 4. 多人规则（仅缩放与协作）

| 人数 | 怪物血量 | 怪物伤害 | 金币 | Boss 额外 |
|---|---|---|---|---|
| 1 | ×1.0 | ×1.0 | ×1.0 | — |
| 2 | ×1.6 | ×1.15 | ×1.25 | +10% 血 |
| 3 | ×2.1 | ×1.25 | ×1.45 | +10% 血 |
| 4 | ×2.6 | ×1.35 | ×1.65 | +10% 血 |

- 掉落：金币/材料共享；装备独立。
- 存档归属：主机存世界进度；客机存自身角色。
- 任何多人存档可由主机切回单人继续，不锁内容。

## 5. 量化验收指标

| 指标 | 目标 | 当前证据 |
|---|---|---|
| 新手首件蓝装 | ≤10 分钟 | 无运行证据 |
| 首个精英/Boss | ≤30 分钟 | 无运行证据 |
| 单局时长 | 15-30 分钟 | 无运行证据 |
| 全流程时长 | 15-25 小时 | 无运行证据 |
| 读档成功率 | >99.5% | 无运行证据 |
| 崩溃率 | <0.5% | 无运行证据 |
| 单人通关率 | >35% | 无运行证据 |
| 本地多人使用率 | >25% | 无运行证据 |

> 以上指标为验收目标，需 QA 在 S7 提供可复现测量方法；当前无运行证据，不计为已达成。

## 6. 失败恢复总表

| 场景 | 恢复策略 |
|---|---|
| 单人死亡 | 回最近篝火，消耗复活币 |
| 多人倒地 | 3 秒扶起，否则回篝火 |
| 全员倒地 | 回城，保留装备 |
| 掉队（同屏） | 3 秒传送队友身边 |
| 卡死房间 | 重置本层，保留装备 |
| 存档损坏 | 加载备份 + CRC 提示 |
| 版本不匹配 | 自动迁移 / 客机只读 |
| 加载超时 | 重试或回主菜单 |
| 未捕获异常 | 回最近篝火，保留日志 |
