## 2. 升级预演场景

### 场景 A：补丁升级（Patch，如 v0.1.0 → v0.1.1）

- 范围：缺陷修复、文案修正、掉落权重微调、崩溃修复；不改存档结构、不改状态机主链。
- 受影响流程：S5 战斗与掉落（SRC-010）、S6 商店/篝火/事件（SRC-011）、S13 错误恢复（SRC-018）。
- 受影响数据：无存档结构变更；掉落权重表（SRC-010）。
- 受影响接口：无契约变更（假设补丁不改接口签名）。
- 通过标准：
  1. M-5 读档成功率不低于基线且 >99.5%（SRC-015）。
  2. M-6 崩溃率不高于基线且 <0.5%（SRC-020）。
  3. M-10 掉落权重断言通过（SRC-010）。
  4. 旧存档可直接读取，无迁移提示（SRC-015）。
  5. 失败恢复总表（SRC-021）全部场景回归通过。
- 回滚时间：≤5 分钟（回退二进制，存档无需回滚）。
- Go/No-Go：
  - Go：上述 5 项全通过，且无新增高严重度缺陷。
  - No-Go：读档成功率下降、崩溃率上升、掉落权重断言失败、任一失败恢复场景回归失败。

### 场景 B：小版本升级（Minor，如 v0.1.x → v0.2.0）

- 范围：新增房间类型/事件、强化重铸数值调整、多人缩放系数调整（仅 1/2 人档位）、UI 流程调整；可能新增存档字段（向后兼容）。
- 受影响流程：S4 迷宫循环（SRC-009）、S6 商店/篝火/事件（SRC-011）、S9 回城（SRC-014）、S10 存档/读档（SRC-015）、S11 双人复活（SRC-016）。
- 受影响数据：存档新增字段（需默认值回填）、强化/重铸数值表（SRC-014，当前未量化，见 QR-6）。
- 受影响接口：存档 schema 版本号、房间生成不变量（SRC-009：每层 1 篝火/1 商店、钥匙门≤1）。
- 通过标准：
  1. 旧存档自动迁移成功，关键字段不丢（SRC-015）；迁移失败可回退备份。
  2. 同种子生成确定性保持（SRC-009）。
  3. 房间生成不变量回归通过：每层 1 篝火、1 商店、钥匙门≤1、主路径连通（SRC-009）。
  4. 多人缩放仅 1/2 人档位验证（SRC-019），3/4 人档位不纳入。
  5. M-1/M-2/M-3 不劣化超过基线 10%（阈值待确认，见 open_questions）。
  6. 双人复活 3 秒生效、全员倒地回城（SRC-016）。
- 回滚时间：≤15 分钟（回退二进制 + 回退存档 schema；需保留迁移前备份槽）。
- Go/No-Go：
  - Go：迁移成功率 100%（测试集）、不变量回归通过、指标不劣化在阈值内。
  - No-Go：迁移丢字段、同种子生成不确定、房间不变量破坏、指标劣化超阈值。

### 场景 C：大版本升级（Major，如 v0.x → v1.0，含存档结构变更）

- 范围：存档结构重构、状态机主链调整、多人规则扩展（若 P1 局域网立项）、经济系统调整；可能不向后兼容。
- 受影响流程：S2 CHAR_SETUP（SRC-007）、S4 DUNGEON_LOOP（SRC-009）、S7 BOSS_ROOM（SRC-012）、S9 TOWN（SRC-014）、S10 SAVE_LOAD（SRC-015）、S12 PAUSE（SRC-017）。
- 受影响数据：全部存档字段（角色属性、背包、装备、金币、任务、地图种子、已开房间、Boss 状态、设置、版本号，SRC-015）。
- 受影响接口：存档 schema、状态机转移契约（SRC-004）、多人缩放契约（SRC-019）。
- 通过标准：
  1. 迁移链（v0.x → v1.0）在测试集上成功率 100%，关键字段零丢失（SRC-015）。
  2. 迁移失败可回滚到旧版本且旧存档可读，回滚演练通过。
  3. 状态机主链（SRC-004）全状态可达性回归通过，含旁路 PAUSE/SAVE_LOAD/ERROR_RECOVERY。
  4. Boss 三阶段前摇可辨识、超时 30s 强制推进（SRC-012）回归通过。
  5. M-5 读档成功率 >99.5%、M-6 崩溃率 <0.5%（SRC-020）。
  6. 单人完整可通关硬约束回归通过（SRC-001/SRC-002）。
- 回滚时间：≤30 分钟（含存档回滚与用户提示）；若迁移不可逆，需提前公告并保留旧版本可执行文件。
- Go/No-Go：
  - Go：迁移 100% 成功、回滚演练通过、状态机与硬约束回归通过、M-5/M-6 达标。
  - No-Go：迁移丢字段、回滚失败、状态机不可达、硬约束破坏、M-5/M-6 不达标。

## 3. 受影响面矩阵（跨场景）

| 维度 | 场景 A 补丁 | 场景 B 小版本 | 场景 C 大版本 |
|---|---|---|---|
| 状态机主链（SRC-004） | 不变 | 局部 | 可能调整 |
| 存档结构（SRC-015） | 不变 | 新增字段 | 重构 |
| 掉落权重（SRC-010） | 可能调整 | 可能调整 | 可能调整 |
| 多人缩放（SRC-019） | 不变 | 1/2 人档位 | 1/2 人档位（3/4 人非 MVP） |
| 失败恢复（SRC-021） | 回归 | 回归 | 回归+重设计 |
| 量化指标（SRC-020） | 不劣化 | 不劣化≤10% | 重新基线 |

## 4. 回滚预案

| 场景 | 回滚对象 | 回滚步骤 | 回滚时间上限 |
|---|---|---|---|
| A 补丁 | 二进制 | 替换可执行文件，存档不动 | ≤5 分钟 |
| B 小版本 | 二进制 + 存档 schema | 回退二进制，加载迁移前备份槽 | ≤15 分钟 |
| C 大版本 | 二进制 + 存档 + 用户公告 | 回退二进制，恢复迁移前全量备份，公告 | ≤30 分钟 |

> 依赖：SRC-015 双备份 + CRC 校验是回滚可行性的前提；存档介质未定（B-2）前回滚步骤不可验证。

## 5. Go/No-Go 汇总

| 场景 | Go 条件 | No-Go 条件 |
|---|---|---|
| A | 5 项通过、无新高严重度缺陷 | 读档/崩溃/掉落/失败恢复任一回归失败 |
| B | 迁移 100%、不变量通过、指标不劣化≤10% | 丢字段、生成不确定、不变量破坏、劣化超阈值 |
| C | 迁移 100%、回滚演练通过、状态机与硬约束通过、M-5/M-6 达标 | 丢字段、回滚失败、状态机不可达、硬约束破坏、指标不达标 |

> 全局前置：B-1（基线缺失）与 B-2（存档介质未定）未解除前，所有场景默认 No-Go。
