# 07 · 版本与发布策略（第一章 / MVP）

> 角色：release-strategist。本文面向发版与升级：版本方案、兼容性矩阵、数据迁移、特性开关、灰度、回滚与发布门禁。
> 证据纪律：事实引用 `SRC-###`；无引用处标注为假设。

## 1. 范围与前提

- 产品范围：第一章 5 层、3 职业、20 怪、1 Boss、50 装备、单人 + 本地同屏 2 人、存档、背包、强化、商店、篝火（SRC-002）。
- 非目标：交易、云存档、远程同乐/在线匹配、人数专属机制、反作弊、内购、多周目、手柄热插拔完整矩阵（SRC-003）。
- 硬约束：单人离线完整可通关为第一优先级（SRC-001）。
- 本文所有发布策略均以“不破坏单人可通关与存档可恢复”为红线。

## 2. 版本方案

### 2.1 版本号格式（建议，待确认）

- 格式：`MAJOR.MINOR.PATCH+BUILD`（语义化）。
- MAJOR：存档结构不兼容变更（需迁移或拒绝加载）。
- MINOR：新增内容/功能（向后兼容存档）。
- PATCH：修复与数值调整（向后兼容）。
- BUILD：构建号/提交哈希，写入存档与日志。
- 现状缺口：文档仅在存档内容中提及“版本号”（SRC-015），未定义格式与用途 → 见 RS-1。

### 2.2 发布通道

| 通道 | 用途 | 放量 | 存档 |
|---|---|---|---|
| internal | 每日构建、内部验证 | 团队 | 可丢弃 |
| closed-beta | 封闭测试 | 邀请制 | 需迁移保障 |
| ea | 抢先体验 | 分阶段 | 需迁移保障 |
| release | 正式 | 全量 | 需迁移保障 |

- 通道枚举与构建元数据需写入存档与日志（RS-1）。
- 离线买断制无服务端灰度，灰度以构建分发实现（RS-7）。

## 3. 兼容性矩阵

### 3.1 存档兼容

| 旧版本 → 新版本 | 策略 | 依据 |
|---|---|---|
| 同 MAJOR，MINOR/PATCH 升级 | 直接加载 | SRC-015 |
| 跨 MAJOR 升级 | 自动迁移（迁移链） | SRC-015 |
| 迁移失败 | 回退迁移前备份 + 提示 | SRC-015、SRC-021 |
| 新版本存档在旧版本打开 | 拒绝加载并提示（不静默损坏） | 假设，需确认 |

- 文档仅写“版本不匹配→自动迁移，客机角色只读提示”（SRC-015），无迁移链与失败回退细节 → RS-2。
- 存档介质未定（localStorage vs IndexedDB，SRC-022）直接影响迁移实现 → RS-8，列为 Gate-0。

### 3.2 行为契约兼容（运行时规则）

以下规则变更需版本说明 + 回归用例，避免升级后行为漂移：

| 契约 | 来源 | 变更风险 |
|---|---|---|
| 掉落品质权重（白40/绿30/蓝20/紫8/橙2；Boss 保底蓝，紫20%、橙5%） | SRC-010 | 玩家收益预期 |
| 多人缩放系数（1人×1.0/×1.0/×1.0；2人×1.6/×1.15/×1.25，Boss +10%） | SRC-019 | 难度与平衡 |
| Boss 三阶段与 30s 超时强制推进 | SRC-012 | 战斗可完成性 |
| 强化 +1~+9 失败不掉级；重铸保底 | SRC-014 | 经济与体验 |
| 房间生成不变量（每层 1 篝火/1 商店、钥匙门≤1、主路径连通） | SRC-009 | 可通关性 |

- 进行中的 Boss 战存档在升级后建议回退到 Boss 前自动存档点（SRC-012 已有该恢复点）→ RS-9。

### 3.3 平台/输入兼容

- MVP 仅保证启动前接入的手柄可用（SRC-003 NG-8）；输入抽象层是否存在待确认（SRC-022）。
- 本地同屏 2 人为 MVP 上限（SRC-002）；3/4 人档位（SRC-019）超出范围 → RS-3。

## 4. 数据迁移

### 4.1 迁移框架（建议）

1. 加载存档 → 读取版本号与 CRC（SRC-015 双备份 + CRC）。
2. 若版本低于当前：按迁移链 vN→vN+1 逐级执行。
3. 迁移前自动复制一份“迁移前备份”。
4. 迁移后校验关键字段（角色属性、背包、装备、金币、任务、地图种子、已开房间、Boss 状态、设置、版本号，SRC-015）。
5. 校验失败 → 回退迁移前备份 + 提示“存档迁移失败，已回退备份”。

### 4.2 迁移测试

- 建立“黄金存档”样本集（每版本至少 1 份），CI 中执行迁移回归。
- 迁移回归通过为发布门禁项（RS-2、RS-12）。

### 4.3 介质迁移

- 若后续从 localStorage 切换到 IndexedDB（或反之），需一次性导入工具与校验；介质决策为 Gate-0（RS-8）。

## 5. 特性开关

| 开关 | 默认 | 作用域 | 说明 | 依据 |
|---|---|---|---|---|
| `mp.maxPlayers` | 2 | 全局 | MVP 锁定 2；3/4 人档位关闭 | SRC-002、SRC-019、RS-3 |
| `mp.lan` | off | 全局 | 局域网联机为 P1 | SRC-003 NG-3 |
| `cloud.save` | off | 全局 | 云存档非 MVP | SRC-003 NG-2 |
| `mp.scaling.tier34` | off | 全局 | 3/4 人缩放档位 | SRC-019、RS-3 |
| `debug.resetFloor` | off | 开发 | 卡死重置本层按钮（SRC-009）仅调试可见 | SRC-009 |

- 开关需有名称、默认值、作用域、灰度策略、下线条件（RS-6）。
- 发布门禁校验：不存在可达的 3/4 人路径；关闭开关不导致崩溃。

## 6. 灰度策略

离线单机无服务端灰度，采用构建分发灰度：

| 阶段 | 对象 | 放量判据 | 观测指标 |
|---|---|---|---|
| G0 internal | 团队 | 冒烟通过 | 崩溃、加载失败 |
| G1 closed-beta | 邀请 | 迁移回归通过、无 P0 | 崩溃率、读档成功率 |
| G2 ea-10% | EA 用户 10% | 崩溃率 <0.5%、读档成功率 >99.5% | SRC-020 指标 |
| G3 ea-50% | EA 用户 50% | 同上且无存档损坏报告 | 同上 |
| G4 release | 全量 | 同上 | 同上 |

- 指标阈值来自 SRC-020（崩溃率 <0.5%、读档成功率 >99.5%），但当前无运行证据（SRC-020）→ RS-4。
- 崩溃/存档指标采集方式需定义（本地日志 + 用户同意上报）→ RS-7。

## 7. 回滚

### 7.1 触发条件（建议）

- 崩溃率超阈值（>0.5%，SRC-020）。
- 存档损坏/迁移失败率超阈值（待定）。
- 出现阻断单人通关的 P0 缺陷（违反 SRC-001 硬约束）。

### 7.2 回滚目标与存档策略

| 场景 | 回滚目标 | 存档策略 |
|---|---|---|
| PATCH 回滚 | 上一 PATCH | 存档兼容，直接可用 |
| MINOR 回滚 | 上一 MINOR | 新存档字段降级忽略，旧版本可读（需验证） |
| MAJOR 回滚 | 上一 MAJOR | 迁移后存档不可逆 → 提供迁移前备份恢复 |

- 文档失败恢复总表（SRC-021）仅覆盖运行时异常，未覆盖发布级回滚 → RS-5。

### 7.3 回滚演练

- 每次 MAJOR 发布前执行一次回滚演练：安装旧版 → 加载新版存档（预期拒绝/降级）→ 恢复迁移前备份 → 验证可玩。
- 演练记录纳入发布门禁（RS-12）。

## 8. 发布门禁清单

| 门禁 | 判据 | 依据 |
|---|---|---|
| G-0 存档介质决策 | 已拍板 localStorage/IndexedDB | SRC-022、RS-8 |
| G-1 版本号与通道 | 版本格式、通道枚举、构建元数据写入存档 | RS-1 |
| G-2 迁移回归 | 黄金存档集全部通过 | RS-2 |
| G-3 量化指标 | 崩溃率 <0.5%、读档成功率 >99.5% 等有测量证据 | SRC-020、RS-4 |
| G-4 单人可通关 | 单人完整通关冒烟通过 | SRC-001 |
| G-5 多人范围 | 无可达 3/4 人路径 | SRC-002、SRC-019、RS-3 |
| G-6 回滚演练 | 演练通过 | RS-5、RS-12 |
| G-7 特性开关 | 开关清单与默认值就绪 | RS-6 |

## 9. 升级影响与用户沟通

- 升级影响面：存档结构、掉落权重、多人缩放、Boss 阶段机、强化/重铸数值（SRC-010、SRC-012、SRC-014、SRC-019）。
- 变更日志模板：玩法数值、存档兼容、已知问题（RS-11）。
- 迁移失败文案：主菜单提示“存档迁移失败，已回退备份”，提供继续/新游戏路径（SRC-006、RS-10）。
