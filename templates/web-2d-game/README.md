# 迷宫冒险家 · 第一章 MVP

这是产品设计文档对应的**可运行第一章垂直切片**：5 层 × 8–12 房间 + Boss，3 职业、技能、装备词条、商店/篝火/事件、3 槽存档和本地双人。

## 运行

```bash
cd game
python -m http.server 8787
# 浏览器打开 http://localhost:8787/
```

Windows 可直接双击 `play_game.bat`。

## 操作

- P1：`A/D` 移动，`W/Space` 跳跃，`Shift` 闪避，`J` 普攻，`U` 重击，`K` 技能，`L` 药水，`E` 交互
- P2：方向键移动，`↑` 跳跃，`Ctrl` 闪避，`/` 普攻，`M` 重击，`.` 技能，`,` 药水，`Enter` 交互
- `I` 背包/装备，`Q` 任务板，`Esc` 暂停，`F5`/右下角“保存进度”即时存档，`F9` 读档
- 战斗中每 15 秒自动保存一次，关闭页面前再保存；商店/篝火/事件关闭后也会自动落盘

## MVP 已实现

- 第一章 5 层，每层 8–12 个普通房间 + 1 个 Boss 房。
- 房间类型：战斗、跳台、宝箱、商店、篝火、事件、精英、Boss。
- 3 职业：剑士（旋风斩/盾冲）、法师（火墙/冰环）、游侠（箭雨/后跳射击），带 MP、双技能冷却、闪避和重击。
- 敌人：近战/投掷/自爆/飞行，精英词缀（护盾/加速/吸血/分裂），三阶段 Boss。
- 装备：5 部位、5 品质、2–4 条词条、背包 60 格、装备/分解、+1~+9 强化、重铸。
- 商店/篝火/宝箱/事件：购买、休息、存档、强化、随机事件。
- 存档：3 个槽位、CRC 校验、版本迁移、自动存档。
- 本地双人：共享镜头、P2 独立 HP/MP、倒地互扶。
- 等级 1–30、经验成长；任务板（Q）3 个第一章任务与奖励。
- 背包 60 格；仓库 200 格尚未做 UI（后续补齐）。
- 三档难度与人数动态缩放（1/2/3/4 人表）。
- 测试：`node --test game/tests/game_logic.test.mjs`、`node game/tests/smoke.mjs`。

## 与正式版的差距

- 当前是 HTML5 Canvas 验证切片，正式版迁移 Unity/Godot，补美术、音频、手柄、局域网、云存档、完整 50 件装备资产和 15–25 小时内容。
- 本地双人先支持 2 人；3–4 人缩放表与 UI 已预留，但键盘位需要手柄/额外键位。
- 当前为灰盒视觉，不是最终像素美术。
